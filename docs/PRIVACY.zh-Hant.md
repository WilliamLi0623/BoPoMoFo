# Bopomofo 隱私聲明

_最後更新：2026-11-21。適用於本倉庫建置的 Bopomofo 各版本。_

## 營運方

Bopomofo 由 **Xuanming Li（個人開發者）** 營運，所在地加拿大。聯絡方式：xuanming.li0623@gmail.com。

**資料存放地。** 登入使用者的雲端資料存於營運方的 Supabase 專案，部署於**新加坡（ap-northeast-1）**。

## 摘要

Bopomofo 採本機優先：學習進度一律先存在你的裝置上。只有在你登入之後，雲端才會參與，且僅用於下述學習資料。沒有任何統計分析、廣告、追蹤或當機回報。

## 存在裝置上的資料

- **學習事件**（本機）：練習了哪個項目（符號或音節）、技能類別、對錯、作答內容、作答時間與提示/重試次數、時間戳。
- **複習狀態**：每個項目的間隔重複排程（穩定度、到期日）。
- **測驗課程**：進行中與已完成的課堂紀錄。
- **混淆資料**：你選過的錯誤選項，用於針對弱點加強。
- **設定**：介面語言；登入後會有一條「同步綁定」，把這台裝置的學習檔案綁定到你的帳號（首次同步即綁定；改登其他帳號不會搬移本機檔案）。
- 全部存在應用程式資料目錄裡的一個 SQLite 資料庫。
- 訪客模式下，學習功能不進行任何網路呼叫，並有自動化測試把關。

## 登入後存在雲端的資料

以 Google 登入會建立 Supabase 託管的帳號。同步範圍限於上述學習資料（事件、複習快照、混淆資料、設定、同步狀態）與設定檔/裝置紀錄，全部以你的 user id 歸屬，並以僅限本人的資料列安全政策保護。應用程式內只會包含可公開的 publishable key，絕不包含特權金鑰。

聽力練習的音檔隨應用程式打包，不從網路下載，也不含任何個人資料。

## 第三方服務

- **Supabase** 託管選用同步與帳號刪除所需的認證與資料庫。
- **Google** 是登入身分提供者。應用程式不請求基本認證以外的任何權限，也永遠不會接觸你的密碼。
- 發音音檔來自數位發展部 CNS11643 開放資料庫，於建置時打包。

## 備份與匯出

你可隨時在設定中把學習進度匯出成 JSON，並匯入任何裝置。沒有自動雲端備份；這份 JSON 就是可攜的備份。

## 帳號刪除

在設定 → 帳戶 → 刪除帳戶中刪除帳號，會一併刪除 Supabase 認證身分，並透過外鍵串聯刪除該帳號在雲端的每一筆資料。裝置上的資料只有在你同時勾選「刪除本機資料」時才會清除。無法使用應用程式時的刪除說明：
https://github.com/WilliamLi0623/BoPoMoFo/tree/main/web/account-delete

## 保存期限

本機資料保存到清除應用程式資料或解除安裝為止。雲端資料存於 Supabase 新加坡區（ap-northeast-1），保存到你刪除帳號為止，刪除時與身分一併移除（外鍵串聯清除 profile、devices、learning events、snapshots、confusion data、settings、sync state）。方案若含自動備份，備份僅在 Supabase 該方案的官方保留期限內存在，逾期即刪除。已刪除的帳號無法復原。

## 你的權利

**加拿大（PIPEDA）。** 你可查閱自己的個人資訊、要求更正、隨時撤回同意。登出或在「設定 → 帳戶 → 刪除帳戶」刪除帳號即為行使刪除權；來信請求會在 PIPEDA 時限內處理。你可向加拿大隱私專員辦公室（opc.ca）申訴。

**歐盟/英國使用者。** 若你在歐盟/英國使用本服務，另享有查閱、更正、刪除、可攜與反對權，以及向監管機關申訴的權利。同步學習資料的合法依據為你的同意（登入並開啟同步時給予）；登出或刪除帳號即可撤回。
